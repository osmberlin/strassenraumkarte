# Ink 19 — railways, opaque carriageways

- Railways as the old-map sign: double line with cross ties (denser on main lines, sparser on sidings/spurs), drawn before the streets.
- Carriageways are now filled with paper before their stipple, so a bridge occludes the tracks below it. The parchment blotches moved to the very end of the paint stack (otherwise the paper fill would show as flat patches).
