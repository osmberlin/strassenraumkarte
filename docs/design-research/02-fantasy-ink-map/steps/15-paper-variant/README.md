# Ink 15 — variant: black on white

```bash
SRK_INK_PAPER=white srk-render --layers ink …
```

Pure black ink (`#151515`) on white paper (`#FBFAF6`), no parchment blotches — for print and two-colour printing (black + one spot colour). The accent stands out much more than on parchment.

`sheet.jpg` is the default sepia version; `paper.jpg` compares sepia (left) and white (right) at Schillerpromenade.
