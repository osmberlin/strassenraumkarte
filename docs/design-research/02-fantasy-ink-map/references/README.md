# References

Reference images are kept **locally only** and are ignored by git (see `.gitignore`), because most of them are third-party work.

- `web/`: images downloaded during the research. Each file is listed with its source URL in [`../research-notes.md`](../research-notes.md) (table "Reference examples"). Public-domain items (Wikimedia Commons) are marked there; if one of them is worth keeping in the repo, move it out of `web/` into this folder and add its licence line below.
- `user/`: screenshots collected by hand. Drop them here, then add a line per image to the list below (what it shows, why it matters, source).
