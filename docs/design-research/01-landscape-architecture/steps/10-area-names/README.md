# LA 10 — area names

- Names of large named areas (`landuse` park, recreation ground, cemetery, garden, …) in Avenir Next Demi Bold, spaced capitals, centred on `ST_PointOnSurface` of the whole polygon (world-stable). Shown when the area covers ≥ 40 000 px² at the current zoom; size grows gently with area.
- Street labels: one label per name and place (dual carriageways no longer print the name twice).

**Look at:** `detail-nw.jpg` (Hasenheide / Columbiadamm at z17).
