# LA 11 — variant: vivid planting palette

The open question "pastel or saturated?" as a switch:

```bash
SRK_LA_PALETTE=vivid srk-render --layers la …
```

Only the planting tones change (lawn `#BCD39A`, meadow `#B3C68C`, shrubs `#93AC72`, crowns `#7FA05A … #A3B776`); paper, streets and buildings stay. `sheet.jpg` shows the default (board) palette; `compare.jpg` puts board (left) and vivid (right) side by side for scenes A and C.

**Verdict (Claude):** board is calmer and closer to the reference pin; vivid reads more like a contemporary competition plan and makes parks pop on a city map. Worth deciding by looking at the whole Schillerkiez in the viewer.
