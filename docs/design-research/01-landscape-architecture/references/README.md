# References

Reference images are kept **locally only** and are ignored by git (see `.gitignore`), because most of them are third-party work.

- `web/`: images downloaded during the research. Each file is listed with its source URL in [`../research-notes.md`](../research-notes.md) (table "Reference examples"). Public-domain items (Wikimedia Commons) are marked there; if one of them is worth keeping in the repo, move it out of `web/` into this folder and add its licence line below.
- `user/`: screenshots collected by hand. Drop them here, then add a line per image to the list below (what it shows, why it matters, source).

| `user-la-crop-board-details.jpg` | 1:1 crops: palette pin with hex values, second palette strip, white urban plan, red crossing, dense canopy plan, tree symbol sheet, garden plan, village plan | See below |

Palette pin (exact hex values): `#D7D1BE #EAE9E3 #CBD4BC #A6A48C #85835F` / `#7C735F #5F5E3E #544C37 #6C6B5A #42412E`.
Second palette strip (read by eye): dark petrol, blue-grey, pale blue, blush pink, khaki, ochre, olive greys, pale grey.

Recurring traits on the board:
- Buildings: **pure white volumes** with a thin grey outline and soft shadow; the ground around them is very light warm grey.
- Trees: translucent discs with a thin outline and a **centre dot**, overlapping; occasionally radial or scalloped symbols; a symbol sheet with ~60 variants.
- Ground: soft watercolour grass texture, light concrete texture for paving, muted khaki meadows.
- Accent: a **red-brown street surface** (cycle street / shared space) as the only saturated colour.
